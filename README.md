# How to Fish Mod Pack

How to Fish向けの非公式・自作MODパックです。ゲーム本体は含まれていません。

島でのラウンド制ゾンビ戦、武器を抽選するミステリーボックス、追加武器、海のボス（メガロドン・オクトパス）、MODを切り替える配電盤を追加します。

## ダウンロード

[最新版の配布ページ](https://github.com/famgameworks/how-to-fish-modpack/releases/latest)

**Assetsの `HowToFish-ModPack-v1.12.1.zip`** を取得してください。GitHubが自動生成する「Source code (zip)」はMODの導入用ではありません。

Windows版How to Fishを別途所有・インストールしている必要があります。ゲーム更新により動作しなくなる場合があります。

## 導入

1. ゲームを終了し、セーブデータをバックアップします。
2. 配布ZIPを展開します。
3. `install.bat` を実行し、ゲームのインストール先を確認します。
4. 同梱の `導入方法.txt` を読み、通常どおりゲームを起動します。

削除はゲーム終了後に同梱の `uninstall.bat` から行えます。設定やログ、無関係なMODを保持することを隔離環境で検証しています。

## v1.12.1

海のボスを呼ぶ専用の餌2種類を追加しています。呼び出しに成功した場合だけ消費し、条件が合わない場合は消費しません。所持数はMOD側の専用ファイルへ保存します。

- 血染めの撒き餌：水深10m以上の沖でメガロドンを呼びます。
- 深海の光るカニ：島の岸に近い水深2.4m以上の場所でオクトパスを呼びます。

詳細は配布ZIPの `導入方法.txt` と `更新履歴.txt` を参照してください。
